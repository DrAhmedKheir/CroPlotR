  P1D    : Photoperiod sensitivity (%)
            Current range: 40-90, Initial: 70
            Effect: Controls flowering response to day length
  
  P5     : Grain filling duration (°C·d)
            Current range: 450-650, Initial: 550
            Effect: Controls grain filling period length
  
  G1     : Kernel number coefficient
            Current range: 18-30, Initial: 24
            Effect: Controls grains per unit biomass
  
  G2     : Standard kernel weight (mg)
            Current range: 38-52, Initial: 45
            Effect: Controls individual grain size
  
  G3     : Stem weight coefficient (g)
            Current range: 1.5-3.0, Initial: 2.2
            Effect: Controls biomass partitioning
  
  PHINT  : Phylochron interval (°C·d)
            Current range: 85-105, Initial: 95
            Effect: Controls leaf appearance rate
