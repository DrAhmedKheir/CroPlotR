TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════

Error: "cannot open file 'data/Sakha95_observed_data.csv'"
Fix:
  1. Verify the file exists at: C:\DSSAT48\data\Sakha95_observed_data.csv
  2. Check spelling and capitalization
  3. Run test_setup.R to diagnose

Error: "there is no package called 'dplyr'" (or tidyr, ggplot2)
Fix:
  install.packages(c("dplyr", "tidyr", "ggplot2"))
  Then run the script again

Error: "DSSAT directory not found"
Fix:
  1. Check that DSSAT is installed at C:\DSSAT48
  2. If installed elsewhere, edit line 142 in script:
     DSSAT_DIR <- "C:/YourPath/DSSAT48"

Error: Script runs but nothing happens
Fix:
  1. Make sure you're using source() or "Source" button
  2. Check the R console for messages
  3. If running interactively, call main() explicitly

Error: "Cultivar code SK0010 not found"
Fix:
  1. Open C:\DSSAT48\Genotype\WHCER048.CUL
  2. Check if SK0010 line exists
  3. If not, you'll need to add it or use a different code
