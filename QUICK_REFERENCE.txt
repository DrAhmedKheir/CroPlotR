┌─────────────────────────────────────────────────────────────────────────────┐
│ ⚙️ CONFIGURATION ESSENTIALS                                                  │
└─────────────────────────────────────────────────────────────────────────────┘

Edit calibration_config.R:

  DSSAT_DIR <- "/path/to/dssat"              # DSSAT installation path
  CROP_MODEL <- "MZCER048"                   # Crop model code
  CALIB_PARAMS <- CALIB_PARAMS_MAIZE        # Parameter set
  MAX_ITERATIONS <- 100                      # Optimization limit
  OPTIMIZATION_METHOD <- "L-BFGS-B"         # Algorithm
  EXPERIMENT_FILE <- "experiment.MZX"       # Your experiment file

┌─────────────────────────────────────────────────────────────────────────────┐
│ 📈 COMMON VARIABLES                                                          │
└─────────────────────────────────────────────────────────────────────────────┘

HWAM   Grain yield (kg/ha)                 Range: 0-15,000
CWAM   Total biomass (kg/ha)               Range: 0-30,000
LAIX   Maximum leaf area index             Range: 0-8
GNAM   Grain nitrogen (kg/ha)              Range: 0-300
ADAT   Anthesis date (days after planting) Range: 40-100
MDAT   Maturity date (days after planting) Range: 80-180

┌─────────────────────────────────────────────────────────────────────────────┐
│ 🔧 COMMON TASKS                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

BASIC CALIBRATION:
  source("calibration_config.R")
  source("calibrate_dssat.R")
  results <- main()

CUSTOM PARAMETERS:
  CALIB_PARAMS <- list(
    P1 = c(min = 250, max = 320, init = 285),
    P5 = c(min = 700, max = 900, init = 800)
  )
  source("calibrate_dssat.R")
  results <- main()

VIEW RESULTS:
  print(results$calibration$parameters)
  print(results$report$statistics)

SAVE ADDITIONAL PLOTS:
  library(CroPlotR)
  save_plot_png(results$report$plots$scatter, "my_plots", "_scatter")

RMSE     Root mean square error           Lower is better (units vary)

"DSSAT not found"           → Check DSSAT_DIR path, verify installation
"Observed data not found"   → Check data/observed_data.csv exists
"Package not installed"     → Run: install.packages(c("dplyr","tidyr","ggplot2"))
"CroPlotR not found"        → Run: remotes::install_github("SticsRPacks/CroPlotR@*release")
"Not converging"            → Increase MAX_ITERATIONS, widen parameter bounds
"Poor fit"                  → Check data quality, verify input files
