📊 UNDERSTANDING RESULTS:

  MAPE (Mean Absolute Percent Error):
    < 10%  = ✓ EXCELLENT
    10-15% = ✓ VERY GOOD
    15-20% = ✓ GOOD
    20-30% = ⚠ ACCEPTABLE
    > 30%  = ✗ POOR (needs improvement)
  
  What to check:
    ✓ Overall MAPE < 20%
    ✓ Similar MAPE for Gemiza and Sids
    ✓ Good fit for yield (HWAM)
    ✓ Good fit for phenology (ADAT, MDAT)

❓ QUICK TROUBLESHOOTING:

  Problem: "DSSAT directory not found"
  Solution: Check C:\DSSAT48 exists
            If elsewhere, edit line 129 in script
  
  Problem: "Insufficient observed data"
  Solution: Fill data/Sakha95_observed_data.csv
            Need at least 10 observations total
            Ideally 50 (23 Gemiza + 27 Sids)
  
  Problem: "SK0010 not found"
  Solution: Open WHCER048.CUL and search for "Sakha"
            If not there, add it first
  
  Problem: "Poor calibration (high MAPE)"
  Solution: 1. Check data quality
            2. Increase MAX_ITERATIONS to 300
            3. Widen parameter ranges
            4. Review observed data for errors

🎯 GENETIC COEFFICIENTS (What gets calibrated):

  P1V    : Vernalization requirement (0-45 days)
  P1D    : Photoperiod sensitivity (40-90%)
  P5     : Grain filling duration (450-650 °C·d)
  G1     : Kernel number coefficient (18-30)
  G2     : Kernel weight (38-52 mg)
  G3     : Stem weight (1.5-3.0 g)
  PHINT  : Phylochron interval (85-105 °C·d)
  
  These 7 parameters define Sakha95 growth characteristics
