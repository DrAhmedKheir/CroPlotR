TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: "cannot open file 'data/Sakha95_observed_data.csv'"
Solution: 
  - Make sure you created the "data" folder
  - Verify the CSV file is in: C:\DSSAT48\data\
  - Check that you saved the script in: C:\DSSAT48\

Problem: "DSSAT directory not found"
Solution:
  - Verify DSSAT is installed at C:\DSSAT48
  - If installed elsewhere, edit line 142 in the script:
    DSSAT_DIR <- "C:/YourPath/DSSAT48"

Problem: "Cultivar code SK0010 not found"
Solution:
  - Open C:\DSSAT48\Genotype\WHCER048.CUL
  - Make sure there's a line starting with SK0010
  - If not, add it manually or contact DSSAT support

Problem: Package installation fails
Solution:
  - Check internet connection
  - Try: install.packages("packagename", dependencies=TRUE)
  - Or download packages manually from CRAN

Problem: Calibration takes too long (>1 hour)
Solution:
  - This is normal for multi-site calibration
  - You can reduce MAX_ITERATIONS (line 223) to 100
  - Trade-off: faster but possibly less accurate

DATA FILE FORMAT
═══════════════════════════════════════════════════════════════

Your Sakha95_observed_data.csv has the correct format:

Columns:
  Location   : Gemiza or Sids
  Experiment : GMZA2001 or SIDS2001
  Treatment  : T1, T2, T3, etc.
  Year       : Actual year (1980-2021)
  Date       : Observation date (YYYY-MM-DD)
  Variable   : HWAM, H#AM, HWUM, ADAT, MDAT
  Value      : Measured value
  SD         : Standard deviation

Example rows:
Gemiza,GMZA2001,T1,1980,1980-04-29,HWAM,5129.5,250
Sids,SIDS2001,T1,1982,1982-04-28,HWAM,7067,353


═══════════════════════════════════════════════════════════════
WHAT EACH VARIABLE MEANS
═══════════════════════════════════════════════════════════════

HWAM  : Grain yield (kg/ha)
        Your range: 5,129 - 11,952 kg/ha

H#AM  : Grain number per m² (grains/m²)
        Your range: 111,707 - 231,577 grains/m²

HWUM  : Individual grain weight (mg)
        Your range: 39.5 - 170 mg

ADAT  : Anthesis date (Day of Year)
        Your range: Day 77 - Day 132

MDAT  : Maturity date (Day of Year)
        Your range: Day 88 - Day 135


═══════════════════════════════════════════════════════════════
GENETIC COEFFICIENTS BEING CALIBRATED
═══════════════════════════════════════════════════════════════

P1V    : Vernalization requirement (10-35 days)
         Controls response to cold temperatures

P1D    : Photoperiod sensitivity (50-85%)
         Controls response to day length

P5     : Grain filling duration (450-600 °C·d)
         How long grain filling takes

G1     : Kernel number coefficient (20-28)
         Controls how many grains per spike

G2     : Kernel weight potential (40-50 mg)
         Maximum individual grain weight

G3     : Stem weight (1.5-2.5 g)
         Non-grain biomass allocation

PHINT  : Phylochron interval (85-105 °C·d)
         Time between leaf appearances
